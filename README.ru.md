# Clipvey

[English](README.md) · **Русский**

Синхронизирует буфер обмена (текст и картинки) между Mac и Windows в локальной сети.

## Скачать

- **Mac** (macOS 14+, Apple Silicon и Intel): [Clipvey.dmg](https://github.com/lovipomidorku/Clipvey/releases/latest/download/Clipvey.dmg) — перетащите Clipvey в «Программы».
- **Windows** 10/11 x64: [Clipvey.exe](https://github.com/lovipomidorku/Clipvey/releases/latest/download/Clipvey.exe) — один файл, установка не нужна.

Программы пока не подписаны. Mac: при первом запуске откройте «Системные настройки» → «Конфиденциальность и безопасность» и нажмите «Всё равно открыть». Windows: в SmartScreen нажмите «Подробнее» → «Выполнить в любом случае».

При первом запуске разрешите на Mac доступ к локальной сети и к буферу обмена («Всегда разрешать»), на Windows — частные сети в брандмауэре.

Сборка из исходников: `mac/scripts/build.sh --install`, `windows/publish.sh`.

## Использование

1. Нажмите «Связать новое устройство» на обоих компьютерах, на одном выберите другой из списка, введите код и подтвердите «Готово».
2. Новое устройство достаточно связать с любым из уже связанных: данные передаются по цепочке.
3. Переключатель у устройства приостанавливает синхронизацию, «Разорвать связь» удаляет связь.

В настройках: язык интерфейса, имя этого компьютера, свои имена для других устройств, «Передавать картинки», автоматическая проверка обновлений (раз в сутки, установка только после подтверждения).

Не передаются: пароли (скрытые типы буфера), текст больше 1 МиБ, картинки больше 20 МиБ, файлы, оформление.

## Данные

| | Mac | Windows |
|---|---|---|
| Ключ и устройства | `~/Library/Application Support/Clipvey/` | `%APPDATA%\Clipvey\` |
| Журнал | `log stream --predicate 'subsystem == "io.github.lovipomidorku.clipvey"'` | `%LOCALAPPDATA%\Clipvey\clipvey.log` |

## Безопасность

Одноразовый 6-значный код связывания, который не передаётся по сети; шифрование AES-256-GCM с новыми ключами при каждом подключении; подключиться могут только связанные устройства. Протокол: [docs/protocol.md](docs/protocol.md).
