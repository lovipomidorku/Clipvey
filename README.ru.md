# Clipvey

[English](README.md) · **Русский**

Синхронизация текста буфера обмена между Mac и компьютерами с Windows в локальной сети. Скопировали на одном устройстве — вставляете на любом другом.

С iPhone текст доходит через Mac: у Apple есть «Универсальный буфер обмена» между iPhone и Mac, а Clipvey передаёт текст дальше, на Windows. Условия: Mac включён и не спит, iPhone рядом, один Apple ID, включён Handoff.

## Установка

- **Mac:** `mac/scripts/build.sh --install`. Приложение ставится в `~/Applications/Clipvey.app`, значок появляется в строке меню.
- **Windows 10/11 x64:** соберите `windows/publish.sh` и перенесите `dist/windows/Clipvey.exe` на компьютер любым способом. Устанавливать ничего не нужно: файл просто запускается, значок появляется в области уведомлений.

При первом запуске системы задают вопросы, на все нужно ответить «Разрешить»:
- **Mac, доступ к локальной сети.** Без него Clipvey не найдёт другие устройства.
- **Mac, чтение буфера обмена.** macOS 15.4+ спрашивает, когда программа читает буфер. Выберите для Clipvey «Всегда разрешать» в Системных настройках → «Конфиденциальность и безопасность».
- **Windows, брандмауэр.** Разрешите доступ в частных сетях.
- **Little Snitch** (если стоит): разрешите входящие и исходящие соединения Clipvey в локальной сети.

Неподписанный `.exe` при первом запуске вызывает предупреждение SmartScreen. Нажмите «Подробнее» → «Выполнить в любом случае».

## Как пользоваться

1. **Связать устройства.** На обоих нажмите «Связать новое устройство». На одном выберите второе из списка, введите код, который оно показывает, а на втором нажмите «Готово». Код одноразовый и действует 2 минуты.
2. **Несколько устройств.** Каждое новое устройство достаточно связать с любым одним из уже связанных: текст пересылается по цепочке. Если связать больше пар, доставка станет надёжнее, а дублей не будет.
3. **Выключить устройство.** Переключатель рядом с ним выключает синхронизацию, не разрывая связь. Кнопка «Разорвать связь» удаляет связь насовсем.

Что не передаётся:
- **пароли** — то, что менеджеры паролей помечают как секретное;
- **текст больше 1 МиБ**;
- **файлы, картинки и оформление** — в первой версии передаётся только текст.

## Где что лежит

| | Mac | Windows |
|---|---|---|
| Ключ устройства и список устройств | `~/Library/Application Support/Clipvey/` | `%APPDATA%\Clipvey\` (ключ зашифрован DPAPI) |
| Журнал | `log stream --predicate 'subsystem == "io.github.lovipomidorku.clipvey"' --level info` | `%LOCALAPPDATA%\Clipvey\clipvey.log` (меню значка → «Открыть журнал») |
| Настройки | `defaults read io.github.lovipomidorku.clipvey` | автозапуск: `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` |

## Безопасность

- Связывание — по одноразовому коду из 6 цифр. Сам код по сети не передаётся, а подобрать его с одной попытки нереально.
- Все данные между устройствами зашифрованы (AES-256-GCM), ключи сеанса новые при каждом подключении.
- Подключиться может только устройство, с которым установлена связь.
- Подробности — `docs/protocol.md`.
